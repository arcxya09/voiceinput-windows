# 第三方依赖

本构建锁定下列直接及主要间接依赖，完整解析结果见各项目的 `packages*.lock.json`。第三方许可证正文随包放在 `licenses` 中。

| 组件 | 版本 | 许可来源 |
| --- | --- | --- |
| .NET SDK（仅构建） | 10.0.401 | Microsoft 官方发行版 |
| .NET / Windows Desktop Runtime | 10.0.12 | `dotnet-LICENSE.md`、`windowsdesktop-LICENSE.md` 和第三方声明 |
| NAudio.Wasapi / NAudio.Core | 2.2.1 | MIT；Mark Heath，NuGet 元数据与仓库许可证 |
| Microsoft.Data.Sqlite / Core | 10.0.12 | MIT；Microsoft NuGet 包元数据 |
| System.Security.Cryptography.ProtectedData | 10.0.12 | MIT；Microsoft NuGet 包元数据 |
| SQLitePCLRaw core/provider/bundle/lib | 2.1.12 | SQLitePCL.raw 仓库及分发包许可证 |

SQLitePCLRaw 的托管包装层和 SQLite 数据库引擎属于不同组件；按各自分发声明处理，不能把全部依赖统一标为本项目原创。云端模型为 API 服务，不包含在 EXE 内。
