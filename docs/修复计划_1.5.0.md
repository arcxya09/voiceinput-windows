# 1.5.0 全程序审查修复计划

基线：1.4.0 / `4564fc83e8b90332e941e7e74a88bf9d8571f07e`。本次覆盖审查 R01–R20，以及自动分段时间校准、高采样率重采样和未来数据库版本防写入边界。

## 实施顺序与完成条件

1. 保护识别正文：补全中文正负、指数与比较保护；采集原生连续性信息并完整收尾；损坏数据库自动降级。
2. 改善输入体验：尽早启动收音，修正低音量超时，支持只听写，恢复焦点探测和 UIA 查询，调整长文投递预算。
3. 修复词库和 UI：专业大小写、多别名、映射有效原因、最新文本、多显示器、音量与统一状态。
4. 完成持久化与发布：运行期保留策略、持续保存错误提示、服务器最终发布状态核对；运行回归、Windows 构建与离线桌面冒烟测试后发布。

| 编号 | 修复方案 | 验收依据 |
|---|---|---|
| R01 | 中文有符号数量、指数、比较关系纳入确认纠错保护 | 正负/指数/比较不可学习为普通替换，术语纠错仍可用 |
| R02 | 记忆初始化失败后禁用数据库，独立保留听写、设置与复制 | 损坏/未来 schema 不被写入，内存正文可完成 |
| R03 | 采集原生设备位置、QPC 与 discontinuity | 非首包缺口进入会话不完整状态并取消自动输入 |
| R04 | 松键后读取覆盖停止时刻的设备尾包，按边界截取 | 时间线测试不截尾、不多发送边界后样本；实机验证 |
| R05 | 先采集再刷新数据库，启动缓存覆盖启动预算 | 保留上轮词频一致性；首样本延迟留待实机测量 |
| R06 | 超时同时检查识别进展，低 RMS 单独不取消 | 持续轻声 partial 有进展不误停；真正停滞仍超时 |
| R07 | 初始焦点宽限；显式只听写模式 | UIA 不兼容时可独立听写；自动输入模式防护保留 |
| R08 | 浮窗展示最新文字，管理正文自动跟随 | 超过 120 字后最新内容持续可见，用户回看不被强拉 |
| R09 | 状态独立刷新，快捷键和版本动态读取 | 暂停/启用/收尾与界面一致；F8/F9 指引正确 |
| R10 | 浮窗跟随目标显示器，增加音量和计时 | 不激活目标外窗口；混合 DPI 实机检查 |
| R11 | 全链条专业词身份保留大小写 | mA/MA、Co/CO 独立保存、统计和提交 |
| R12 | 每条确认决议保存独立旧写法 | 多别名共存，可分别关闭、撤回 |
| R13 | 管理与执行共用映射分析 | 替换链/冲突显示真实阻断原因 |
| R14 | 在保留语义保护下扩展可验证的最小整理 | 常见口吃与有限标点整理生效，数值/否定/引号不改 |
| R15 | 长文预算包含各批 UIA 查询开销 | 慢查询不因字数预算而人为截断，真实焦点变化仍取消 |
| R16 | 根据说话键动态检查修饰键 | F8/F9 下右 Ctrl 组合键不触发录音 |
| R17 | 设置变更立即清理，并定期维护 | 超期源及派生数据清理；延迟写入不能复活 |
| R18 | 失败保存与正在保存分开，持续显示未保存状态 | 输入成功不覆盖保存失败，重试成功复位 |

## 发布门与验证边界

修复分支通过全部核心/存储回归、锁定依赖的 Windows x64 构建、发布脚本离线回归和桌面冒烟测试后，再合入 main 发布。Windows 冒烟测试检查实际 WPF 页面、DPAPI、SQLite、浮窗和 UIA 工作进程启动，不调用真实麦克风或付费云端接口。

真实语音准确率、首尾音频完整性在具体设备上的表现、跨应用兼容性及混合 DPI 效果仍需 Windows 实机语料验收。应记录原始 ASR 与最终正文、CER/WER、专业词精确匹配、含义误改以及起录/收尾延迟，不能用编译成功替代这些测量。

旧版已经合并删除的大小写词条不能从不存在的数据自动恢复；升级后应重新导入需要并存的专业写法。修复保留现有手动权重、项目边界、纠错确认权限和原始识别文本。
