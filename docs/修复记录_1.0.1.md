# Windows 语音输入法 1.0.1 修复记录

日期：2026-09-12  
适用版本：1.0.0 → 1.0.1  
交付平台：Windows 11 x64，自包含单文件 EXE

## 故障与根因

用户反馈：在目标输入框长按默认右侧 Ctrl 后，立即显示“音频转换或上传中断”，无法正常语音输入。

本次在源码中确认并通过测试复现了一个会导致该提示的故障。百炼正常的中间识别结果允许 `payload.usage` 为 `null`，句子尚未结束时 `sentence.end_time` 也可为 `null`。官方服务端事件示例包含这些值。[百炼服务端事件](https://help.aliyun.com/zh/model-studio/fun-asr-server-events)

旧版分别对空值调用 `TryGetProperty` 和 `TryGetInt64`。这两个方法不会把“JSON 类型不符”视为普通的读取失败，而会抛出 `InvalidOperationException`。接收循环因此中止并取消上传；音频处理循环随后捕获取消异常，显示统一的音频转换或上传错误。提示掩盖了真正的响应解析故障。

使用官方格式的首条中间结果和心跳作为回归输入，旧版结果为 **31 项通过、2 项失败**；失败均为读取 `Null` 值时抛出异常。另一个同源问题是空的结束时间，已一并修正。此复现针对程序代码与协议数据，未连接用户电脑或读取用户账户响应。

## 修复内容

| 位置 | 修复后的行为 |
| --- | --- |
| `BailianProtocol.Parse` | 读取可选用量、开始时间和结束时间前检查 JSON 类型。空用量保持未知；空结束时间保持尚未结束；继续接收后续片段。 |
| ASR 收发循环 | 保存首个服务端或连接错误。后续音频和收尾操作保留原始分类，主动取消不再产生新的虚假网络故障。 |
| 百炼连接提示 | 区分 HTTP 401、403、404、429、服务端故障、连接超时；任务拒绝显示受限长度的 `error_code`。不回显服务端原始错误正文。 |
| 音频转换 | 从录音前确认的格式创建独立解码器；校验声道、编码和块对齐。只读取回调中的有效字节。支持 PCM 8/16/24/32 位、浮点 32/64 位，统一转换到 16 kHz 单声道 PCM16。 |
| 故障传播 | 音频故障绑定当前任务 ID；本轮首个故障不会被后续重复取消消息替换。 |
| 设置页 | 新增 3 秒本地麦克风测试和可复制的最近一次诊断。测试期间暂停按住说话，结束后恢复之前的状态。 |

音频解码器的格式支持不代表任意驱动都能提供该格式；设备打开、WASAPI 实际回调和 Windows 输入兼容性仍需实机验证。此次已复现的直接故障是协议空值解析，并非已经确认用户麦克风格式有问题。

客户端仍先等待 `task-started` 再上传二进制音频，并在收到 `task-finished` 后结束；本次未更换识别模型或接口协议。[百炼 WebSocket 交互流程](https://help.aliyun.com/zh/model-studio/fun-asr-realtime-websocket-api)

## 验证结果

修复后自动测试共 **42 项通过、0 项失败**，其中新增 11 项：

1. 首条中间结果 `usage: null`、`end_time: null` 后仍能接收最终句。
2. 空用量心跳不产生识别错误。
3. 可选用量和时间戳的空值、缺失及异常类型隔离。
4. PCM 8/16/24/32 位的负值、静音和满幅解码。
5. 浮点 32/64 位、双声道与 NaN/Infinity 处理。
6. 格式、块对齐和有效缓冲区边界校验。
7. 正式 ASR 收发代码通过模拟 WebSocket 完成预录、首条中间结果、心跳、最终句和结束；上传字节完整一致。
8. 任务拒绝保留首个错误码，后续音频不会改成取消异常。
9. 启动时主动取消不产生虚假网络错误。
10. 已建立连接的正常中止不通知上传故障。
11. 连接前缓存保持 5 秒上限，溢出明确停止。

Windows WPF 目标编译和 win-x64 单文件发布已完成。完整输出与文件校验见 `docs/验证记录.md` 和 `docs/EXE校验.md`。

测试环境为 Linux x64。未执行真实 Windows 麦克风、全局快捷键、目标文本框投递、DPAPI 和付费云 API 联调；新增本地测试按钮也没有在真实 Windows 上点击验证。交付构建仍为未签名的预发布版。

## 升级与复查

1. 右键旧程序托盘图标，选择“退出”。仅关闭窗口通常仍会留在托盘。
2. 运行 `VoiceInput-Windows-x64-1.0.1.exe`。在“用量与说明”确认版本为 1.0.1。
3. 在记事本等可编辑文本框按住右侧 Ctrl 说话，松开等待尾句与润色完成。
4. 若仍失败，先使用“设置 → 本地麦克风测试（3 秒）”。测试无云端调用、不保存音频。
5. 若本地测试通过而识别仍失败，复制“查看录音诊断”内容及界面错误提示用于进一步定位。无需提供 API Key。

程序沿用 `%LOCALAPPDATA%\RealtimeTranscription\` 中的配置、凭据、记忆和词库。本版不执行数据结构迁移；不要为了替换 EXE 删除该目录。
