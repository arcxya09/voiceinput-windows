# Windows 语音输入法 1.1.0 更新说明

日期：2026-09-12  
平台：Windows 11 x64，自包含单文件 EXE  
基线：技术设计 v3.0、1.0.1 空值解析修复；本文件记录新增功能和设置。

## 可编辑的润色提示词

在“设置 → DeepSeek 轻量润色 → 润色提示词（可编辑）”展开编辑区。首次显示内置默认提示词，可以直接修改、保存，或点击“恢复默认”后保存。支持最多 8,000 字，多行内容随本地设置保存，重启后继续使用。旧版配置没有此字段时自动使用默认提示词。

“试用当前提示词”使用编辑框中的内容和上方 DeepSeek Key，不要求先保存。输入一段最多 600 字的试用文本，界面显示实际可采用的结果及校验提示。试用会产生少量 API 用量。修改正在生效的提示词后，已开始的润色任务仍使用创建请求时的提示词，新请求采用保存后的内容。

提示词可以调整轻量整理的偏好；现有最小改动校验继续保护原意、数字、单位、否定和命中词条。未通过校验的模型输出会回退到原文。修改提示词不会关闭这些保护，也不会使尚未确认的 ASR 草稿提前输入。

默认提示词包含 `current_text`、`protected_terms` 和可选 `previous_text` 的说明，建议编辑时保留这些数据字段的含义。DeepSeek 模型继续使用 `deepseek-flash`，关闭思考，只读取正式正文。

## AI 自动生成专业词库

入口位于“设置 → AI 生成专业词库”。复用上方 DeepSeek API Key，不需要另设接口地址。

例如填写：

> 生成 100 个 HR 领域的专业词条，覆盖招聘、绩效、薪酬、培训和员工关系。使用简体中文，可包含常见英文缩写，不要释义和例句。

把“目标词数”设为 `100`，选择“当前项目”或“全局词库”，点击“生成词库”。数量始终以目标词数字段为准。生成要求最多 1,000 字，每次目标 1—500 个词条。

结果首先进入预览表，可修改词条、类别，勾选或取消勾选。已有词条会标明“已存在”，导入时跳过；同一范围按 Unicode NFC 规范化并忽略英文大小写去重。选择导入范围后，重复状态按该范围重新检查。

点击“导入选中词条”才会写入本地词库。默认勾选“导入后启用”，导入的新词从下一轮识别开始使用；取消该选项则作为待确认候选保存。相同范围的原有词条不会被覆盖。用户仍可在词库页编辑权重、禁用或删除。

生成词条标记为“AI 领域生成”，保存用户的生成要求用于追溯，来源中没有伪造的历史输入证据。系统不会为了生成领域词库自动发送历史记忆、通讯录或原有完整词库。

### 分批、停止与预算

- 每批最多 50 个，100 个目标通常分两批处理；补充请求最多额外两次。模型反复返回重复内容时会提前结束，界面显示实际有效数量。
- 每个请求最多等待 45 秒，整次生成最长 6 分钟。取消或后续批次网络失败时，已完成批次保留在预览中，可以导入。
- 格式错误、空词条、超长词条、控制字符和重复项会被拒绝或过滤。客户端只接受词条文字及类别，ID、范围、状态和来源由本地程序设置。
- 生成与历史词条整理共用“每日词库 AI Token 预算”，默认 50,000。请求前预留额度，收到实际用量后结算；未知用量保留预留额。预算不足时停止后续批次，保留已有结果。大量词条可能需要提高预算。
- 真实模型可能无法一次生成目标数量，界面会显示实际结果，不用虚构词条补足。专业性需要用户在导入前检查。

调用仍使用官方 Chat Completions API。领域词库请求采用 JSON 输出模式，系统提示词同时明确要求 JSON；只有正常结束的完整响应才参与解析。[DeepSeek Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/)

图标由声纹与文本光标组成，采用现有界面的青绿色 `#226E67`、白色和浅绿色 `#BCE9D4`。没有增加程序名称以外的品牌文字。

## 设置与数据兼容

本版沿用 `%LOCALAPPDATA%\RealtimeTranscription\`。配置仍为 schema 3，以新增可选字段扩展；数据库不迁移表结构。旧 Key、快捷键、记忆和词库继续读取原目录。新增设置如下：

| 字段 | 默认值与用途 |
| --- | --- |
| `polishPrompt` | 内置默认提示词；空值或空白按默认处理 |
| `generationRequirement` | HR 领域示例要求，可编辑 |
| `generationCount` | `100` |
| `generationGlobal` | `false`，默认当前项目 |

“保存提示词”只保存提示词及现有其他设置；“保存设置”同时保存编辑页中的 Key 和生成参数。试用与生成可以直接使用上方尚未保存的 DeepSeek Key；需要重启后继续使用时，请点击“保存设置”。

生成预览保存在本次进程内，退出后不保留。需要长期保存的结果应先导入词库。生成要求写入已导入词条的加密负载。提示词与一般生成参数属于非秘密配置，保存在 `settings.json`；不要在提示词中填写 API Key。

### 新增用量类别

- `polish_preview`：提示词试用。
- `term_generation`：领域词库生成。
- `term_budget`：生成与整理共享的预算预留及结算，不与上述实际用量相加计算账单。

## 验证与限制

共 55 项测试通过，0 项失败。新增测试覆盖旧配置默认值、提示词保存与恢复、请求使用自定义提示词、词库模型输出校验、100 词分批生成、数量上限、重复停止、取消与部分失败、DeepSeek 请求结构、空用量和生成来源持久化。

Windows WPF 目标编译与自包含单文件发布通过。ICO 尺寸、矢量源和小尺寸显示已检查。测试使用模拟 HTTP/WebSocket；数据库测试使用测试保护器，正式程序继续使用 Windows DPAPI。

尚未在真实 Windows 上操作新增设置页、调用实际麦克风或使用付费 DeepSeek/百炼账户联调；本构建仍为未签名预发布版。自动测试不能代替真实模型词库质量和界面操作验收。

## 升级

从托盘退出旧版后运行 `VoiceInput-Windows-x64-1.1.0.exe`。在“用量与说明”确认版本为 1.1.0。保留原数据目录，无需删除 Key、记忆或词库。
