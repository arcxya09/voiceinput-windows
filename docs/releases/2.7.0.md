# VoiceInput 2.7.0

## 设置重新整理

设置页原来是一整页长列表，“麦克风与操作”里混着设备、日志、快捷键、上屏方式和开机自启动。现在分成四个分页，底部“保存设置”对所有分页统一生效：

- **输入与麦克风**：按键与录音（按住说话键、长按确认、断句停顿、最长按住、长停顿分段）、上屏方式（直接输入）、麦克风（设备、测试、录音诊断）、启动与托盘。
- **识别与润色**：百炼语音识别（Key、地域、Workspace）、识别效果（自适应灵敏度、智能标点、高精度模式）、DeepSeek 全文润色与提示词。
- **词库与记忆**：文本记忆（保存开关、保留天数）、词库（热词、ASR 上下文、优先级调整、纠错候选）、AI 词条整理（整理许可、自动提取、智能领域词库、每日预算）、从全部历史提取词条。
- **更新与维护**：软件更新、自动更新开关、运行日志导出、数据恢复与项目管理。

首次启动未填写百炼 Key 时，直接打开“识别与润色”分页。左上角显示的版本号改为当前实际版本。

## 手动检查更新

- 托盘菜单新增“检查更新”：打开设置的“更新与维护”分页并立即检查。
- 手动检查发现新版后直接下载并校验（即使关闭了“发现新版后自动下载”），完成后点击“安装并重启”或从托盘菜单安装。
- 检查结果显示检查时间；已是最新版时显示当前版本号。
