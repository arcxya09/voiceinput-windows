# VoiceInput 2.6.0

## 自动安装更新

2.2.0 起软件会检查 GitHub 正式版并在后台下载，但安装仍需手动走安装向导，便携版只能转为安装版。本版把下载后的安装也做成自动的。

- **静默安装并自动重启**：安装版不再打开安装向导。软件保存数据并退出后，安装程序在后台完成升级，再自动重新打开 VoiceInput；设置、词库和历史记录保留。安装中途失败时自动重新打开原版本。
- **便携版原地更新**：便携版改为下载新版便携包，校验后在原文件夹替换 `VoiceInput.exe`、`app/`、`licenses/` 与说明文件，再自动重新打开。文件夹里的其他文件不动；替换失败时恢复原文件，下次打开时在“设置 → 软件更新”提示原因。便携版放在不可写的位置时无法原地更新，会提示原因。
- **一键安装**：新版下载并校验后，托盘弹出提示，点击即可安装并重启；托盘菜单也会出现“安装新版 vX.Y.Z 并重启”。设置页的按钮改名为“安装并重启”。
- **空闲或退出时自动安装**：新选项“电脑空闲或退出程序时自动安装已下载的新版”默认开启。只在管理窗口关闭、托盘菜单未打开、3 分钟没有键盘鼠标操作且没有进行中的识别或管理操作时安装，不会打断听写。从托盘选择“退出”时也会顺便安装，此时不自动重新打开。关闭此选项后，仍可通过托盘提示、托盘菜单或设置页手动安装。

原“托盘空闲 1 分钟后自动退出并打开安装程序”选项由上述选项取代，升级后按默认开启处理。

## 升级说明

从 2.5.0 及更早版本升级到 2.6.0 时仍由旧版本完成：安装版会照旧打开安装向导，便携版会照旧提示改用安装版，建议手动下载 2.6.0 便携包解压覆盖。安装 2.6.0 之后，后续版本即可自动安装。

## 验证

- 回归检查覆盖按安装方式选择安装包或便携包、便携版替换后保留其他文件并清理备份、替换中途失败恢复原文件、便携包结构异常或被修改时拒绝解压。
- Windows CI 实际运行安装程序，确认带 `/UPDATERELAUNCH=1` 的静默升级完成后重新打开已安装的程序。

便携版替换流程与托盘一键安装需要在实际的跨版本升级中复测（2.6.0 → 下一版本）。
