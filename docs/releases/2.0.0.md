# VoiceInput 2.0.0

本版将全部显示界面迁移为原生 WinUI 3，重新设计主窗口、识别浮窗和对话框。

## 界面

- 原生侧边导航组织听写、历史记录、词库、设置和帮助；按系统主题显示，使用 Fluent 控件。
- 听写页集中显示本轮正文、识别阶段、音量与复制、导出和对照入口。
- 词库页集中管理词条、纠错学习和 AI 生成；保留编辑、批量启用、动态词频、来源、导入导出及自动纠正控制。
- 项目创建、术语编辑、确认纠错和正文修订使用原生 ContentDialog；文件打开、保存使用原生 Windows 选择器。
- 托盘右键菜单使用独立的 WinUI 小窗口，支持方向键、Esc 和失焦关闭，不必展开管理主窗口。
- 识别浮窗固定约 360 × 76 DIP，在目标屏幕工作区底部居中。左音量、右计时，中间状态与最新尾句；长语音和保存告警不再撑大窗口。浮窗保持鼠标穿透和不抢焦点。
- 模态编辑和文件选择期间暂不开始新的听写，避免切换正在修改的记录。

## 升级与运行

下载 `VoiceInput-Windows-x64-2.0.0.zip`，完整解压到同一个目录，运行 `RealtimeTranscription.exe`。包内包含 .NET 与 Windows App SDK 原生依赖，不需要单独安装运行时；请保留同目录的 DLL、Assets 和 *.pri 等文件。

升级前从托盘退出 1.x 版本。继续使用当前 Windows 用户的原有数据目录，保留 API Key、设置、项目、历史记录、词库和明确确认的纠错权限；数据库结构与识别、全文润色规则沿用 1.5.0。

支持 Windows 10 1809（17763）及以上和 Windows 11 x64。
