# VoiceInput 2.1.1

修正识别浮窗预览长期只显示省略号，以及托盘菜单、浮窗边缘不平滑的问题。

- 移除 GDI 整数像素圆角裁切和重复的 XAML 外框，改由 Windows DWM 绘制原生圆角、轮廓与阴影。保留浮窗不抢焦点、鼠标穿透及底部居中。
- 预览文字使用实际挂载到窗口的 WinUI TextBlock，在原生布局中按可用宽度显示最新内容，保留完整 Unicode 字素；不再使用脱离窗口的测量控件或布局前的文字宽度。
- 取消和完成等状态通知保留本轮已有文字。新一轮录音清空上一轮预览；尚无识别结果时显示明确提示。
- 回归检查新增首次显示、长文切换短文、隐藏后重开、状态通知、零宽到正常宽度，以及多种字体大小下的预览布局。

继续提供自包含安装版与 Portable 版。沿用原有配置、词库、历史和开机自启动设置。

Windows 自身决定是否显示圆角，Windows 10、虚拟机和远程桌面可能采用方角。自动检查记录实际桌面 DPI；字体大小和布局宽度测试不等同于物理显示器 150% 缩放验收。真实麦克风、云端识别和物理混合 DPI 多显示器仍需实机验证。
