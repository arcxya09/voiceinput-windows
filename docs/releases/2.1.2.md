# VoiceInput 2.1.2

修复 2.1.1 全项目代码审查确认的七项问题，继续提供 Windows x64 安装版和 Portable 版。

- 保存告警覆盖所有会话。切换项目后才返回的写入失败也立即显示，重试仍保存到原会话。
- 历史载入与新录音互斥，载入时检查会话身份并支持取消和超时，避免历史记录覆盖正在开始的新一轮语音。
- 浮窗接收带本轮标识的最终文字，识别完成、取消和快速短句不再因界面刷新合并而漏掉最后的预览。
- 扩展自动纠错的科学单位保护，拦截中文及英文单位名称和 SI 词头组合的量纲或数量级变化。
- 纠错学习跟踪实际修改来源，手动改回原写法后撤销失效来源，避免候选与词频加权继续计入已撤回的纠正。
- 设置、API Key 和本地数据库独立初始化。Key 损坏时保留有效设置、历史和词库，提示重新填写；设置损坏时保留原文件，以关闭自动保存、学习和输入的临时设置恢复界面。
- “完整识别原文”保留已从最终正文删除的确认片段，便于核对原文和修订结果。

新增对应的业务回归和 Windows 界面检查。验证使用临时数据库、模拟的网络响应和隔离输入；不调用真实麦克风或付费云端服务。物理混合 DPI、多显示器及外部应用输入兼容性仍需实机验证。

安装版与 Portable 版沿用现有用户数据及开机自启动设置。升级前先从托盘退出旧版；Portable 请完整解压后运行顶层 `VoiceInput.exe`。
