# VoiceInput 2.1.11

本版修复部分 Windows 10 / 虚拟音频设备在开始录音后被应用的采样完整性检查中断的问题。

## 修复

- 重复设备位置、中断标记及不可信时间戳继续读取有效 PCM，记录异常，不再直接取消整轮识别。首包中断标记仍按正常启动处理。
- 可信时钟保持按松键时间精确裁剪；遇到异常时钟或尾包等待超时，松键后停止设备，再读完缓冲数据。此模式可能包含少量松键后的声音，不承诺逐样本精确边界。
- 设备报告正向音频位置缺口时继续识别、复制文字，提示核对后手动粘贴；不把可能缺字的结果直接输入目标软件。
- 采集线程尝试注册 Windows MMCSS Audio 调度；不可用时继续使用原有线程调度。
- 新增实际缓冲区容量、设备周期、异常包位置/时间戳差值、兼容收尾与缺口汇总日志。每轮最多记录 16 条详细异常包，避免反复异常刷满日志；不记录音频、识别正文或凭据。
- 真实采集故障保留原始提示，浮窗显示“识别失败”，避免启动取消覆盖故障原因或误标为目标校验失败。

## 下载

- `VoiceInput-Setup-2.1.11.exe`：安装版。
- `VoiceInput-Portable-x64-2.1.11.zip`：完整解压后运行根目录 `VoiceInput.exe`，保持内部目录结构。

## 验证边界

新增确定性回归及 Windows 桌面冒烟检查，覆盖异常音频包、停止后排空、真实设备错误、故障提示和缺口结果复制。CI 使用 Windows 构建环境及模拟音频设备，不能替代 Windows 10 17763 和具体驱动的实机录音测试。用户上传的 2.1.10 日志已证明设备启动并返回音频后触发完整性异常，但缺少被拒绝包的元数据，无法确定具体是哪一种驱动时间轴异常。

升级后建议先使用设置中的“测试麦克风”，再长按说一句完整的话。若仍异常，请导出本版日志，新的包级字段可进一步定位。
