# VoiceInput 1.4.0

本版补齐词库“使用 → 统计 → 调整 → 可查看”的流程，并让明确确认的纠错写法真正应用到后续输入。

## 改进

- 新增按项目、不同录音会话计数的词条使用量、人工纠正量及最近时间。保存重试、同轮重复出现不刷高计数；修改、撤销、删除和撤回会话学习许可会同步更新统计。
- 热词在手动权重、项目与置顶设置的基础上，加入有上限的使用与纠错得分，并随时间衰减。活跃词条可进入最多 200 个热词的列表，实际 ASR 权重最多提高两档且始终为 1–5，手动权重不变。
- 新增动态调整开关、词频列、下轮热词预览，以及本轮热词提交状态、实际权重、保护词数量和已应用纠错数量。下一轮录音前重新读取已保存统计。
- 确认学习时可授权“旧写法 → 标准写法”自动纠正；在本地、全文润色前应用，关闭润色也生效，并保留原始识别文本。已学习记录支持单独启用或关闭自动纠正。
- 导入别名、普通手动别名及旧版仅用于追溯的别名不会自动成为替换规则。禁用、修改、删除词条或撤销学习会使相应映射失效。
- 自动纠正不循环替换，不把自身结果计入人工学习；跳过冲突、重叠、数字/单位/否定变化、引文/代码及不完整录音，不跨 ASR 片段替换。手动编辑和恢复原文会同步更新纠正显示。

## 使用与升级

1. 从托盘退出旧版，备份 `%LOCALAPPDATA%\RealtimeTranscription\`，再运行本版 EXE。
2. 现有词库和手动权重继续保留。统计需要开启保存、学习、动态调整及会话学习许可；不会自动回扫全部旧记录。
3. 旧版已学习的纠错默认仍仅用于热词。需要自动纠正时，在“词库 → 纠错学习 → 已学习”中选择相应记录，点击“启用自动纠正”。
4. 在“查看下轮热词”确认选词和权重，在“查看本轮词库”核对当轮提交与纠正情况。

数据库升级为版本 3。回退到 1.3.x 或更早版本需要恢复升级前备份，旧版无法直接打开升级后的数据库。

## 验证范围

发布工作流会运行核心、存储、协调器和输入焦点回归测试，随后构建 Windows x64 自包含 EXE。新增用例覆盖动态排序、计数幂等、项目与许可隔离、来源撤销、数据库升级、确认映射授权与撤销、冲突保护及与全文润色的组合行为。

准确的测试结果随本 Release 的 `build-output.log` 提供。“已提交热词”不等于已验证云端识别准确率；本轮未执行真实麦克风、桌面交互或付费云端听写对照实验。
