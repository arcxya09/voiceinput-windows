# VoiceInput 2.1.4

优化按住说话时的起录反馈、连接等待和文字上屏兼容性。

- 麦克风收到首帧后，胶囊立即显示“正在聆听”；云端识别仍在后台连接，句首音频继续使用有界本地缓存。设备尚未产出音频时显示“准备麦克风”，避免把未启动的采集报为就绪。
- 本轮词库准备与网络握手并行，减少二者串行相加的等待；识别请求仍使用本轮刷新后的热词。
- 保留长按门槛及输入目标确认，通过后才建立识别连接。识别服务确认任务后再按顺序上传缓存音频。
- 修复在麦克风构造期间松键后仍可能新启录的问题。松键、失败和取消后不再显示聆听，上一轮的迟到音量回调不能影响新一轮。
- 录音诊断分别显示“按键至首帧录音”和“按键至识别就绪”的耗时，便于区分设备启动和网络等待。

- 上屏改为按完整 Unicode 字符依次发送，并在字符之间短暂让目标软件处理队列，减少整句突发键入的兼容性问题。保留补充字符、输入保护及部分输入计数；取消或异常后不自动重发。
- 增加真实 Windows 输入检查：在独立的普通/富文本控件中读回“感觉好像就不太准确。”，并覆盖选中文字替换、emoji 和跨批次边界。

验证使用隔离音频源和模拟连接检查生产控制器的启动、慢握手、取消、快速释放和轮次隔离，并在真实 Windows 可执行文件中检查胶囊阶段文字。测试不调用实际麦克风或付费云服务，不承诺固定的实机毫秒提升；实际速度取决于设备、网络与识别服务。上屏检查覆盖受控 Windows 文本控件，具体第三方软件和输入法组合仍需实测，尚不能据此确认用户报告的根因。

继续提供 Windows x64 安装版和 Portable 版。升级前退出旧版；Portable 完整解压后运行顶层 `VoiceInput.exe`。
