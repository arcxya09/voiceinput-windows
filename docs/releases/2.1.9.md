# VoiceInput 2.1.9

- 修正录音启动故障提示：没有输入设备时明确提示未找到可用麦克风，并提醒虚拟机用户接入或映射麦克风。区分打开麦克风、启动采集及连接识别服务等阶段，保留异常类型和 HRESULT；音频权限、设备失效、独占占用、格式及系统音频服务故障给出对应建议。
- 按 WASAPI 文档调整共享模式事件采集的缓冲时长和周期参数，由系统选择缓冲；不再请求固定的 100 ms 缓冲。
- 已选麦克风断开或明确失效时，本轮临时回退到 Windows 默认通信麦克风。设置页保留原设备选择并标明不可用，本地测试与实际录音采用相同规则；权限、忙碌等其他异常不触发设备回退。
- 浮窗显示期间检查实际窗口层级，失去置顶或被重叠窗口遮挡时以不激活窗口的方式恢复。覆盖录音、收尾、完成提示及未保存提醒；隐藏和关闭后停止检查。
- 修正无符号 8 位 PCM 静音包的取值，避免把静音误算成满音量。

继续提供 Windows x64 安装版和便携版，保留 2.1.8 无焦点识别并自动复制、整段粘贴及不恢复旧剪贴板的行为。

验证包含控制器故障注入、设备选择及静音解析回归，以及实际 Windows 窗口层级、无激活、复制粘贴和安装卸载冒烟。GitHub 托管的 Windows 测试环境不是 Windows 10，且未连接真实麦克风或云服务；不能据此断言用户的实际启动错误已复现或已消除。若仍失败，请在设置中先复制“查看录音诊断”的内容，再运行麦克风测试。详见 [Win10 排障与验证](../Win10-startup.md)。
