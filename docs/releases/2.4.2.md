# VoiceInput 2.4.2

## 高精度模式改为按需开启

- 高精度语音复核默认关闭，减少松键后的等待和额外识别调用；设置界面与说明同步更新。
- 新安装、缺少高精度字段的旧配置均使用关闭状态。已保存的显式开关保持不变；此前开启的用户可在“设置 → 百炼语音识别 → 高精度模式”取消勾选。
- 关闭后继续使用实时识别结果，保留已启用的词库纠错、润色和智能标点；不发起整段复核请求。
- 包含 2.4.1 的剪贴板短暂占用恢复、明确复制失败提示和分阶段诊断日志。

## 验证

补充首次安装、旧配置缺字段、开启/关闭保存后重启的回归检查，并验证默认模式不发起额外整段 ASR 请求。保留高精度模式显式开启后的全部识别、回退和取消检查。

非剪贴板上屏方案的比较见 [输入策略研究](../Win10-input.md)。本版继续使用已验证的整段粘贴路径，TSF 接入需作为后续架构改造单独验证。
