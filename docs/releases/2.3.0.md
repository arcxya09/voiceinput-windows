# VoiceInput 2.3.0

- 新增智能领域词库：根据历史输入识别近期话题及较早领域背景，预测可能使用且容易识别出错的专业词。
- 重点筛选同音近音、生僻名称、英文缩写、音译及分词歧义；适度扩展相关术语，排除通用词和无依据的词条。
- 预测词自动以低权重试用，随话题动态调整，保留生成理由和历史依据；不依赖用户在其他软件中的修改，不生成强制替换规则。
- 新增“更新领域词库”“查看领域分析”，支持将预测词确认成个人词条，禁用及删除不会自动恢复。
- 后台分析复用 Token 预算和取消机制，历史删除、修订及学习许可撤回会使相应分析失效。

启用方法：设置 → 记忆与词库 → 智能领域词库，保存设置。需开启文本记忆和允许学习，并配置 DeepSeek Key。升级后默认关闭。

模型判断是预计易错风险，不是实测识别错误率。本版自动测试使用模拟云端响应，实际识别收益需结合个人输入验证。
