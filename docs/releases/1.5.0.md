# VoiceInput 1.5.0

本版按全程序审查 R01–R20 修复语音采集、专业词库、确认纠错、输入、界面和持久化问题。逐项方案见[修复计划](../修复计划_1.5.0.md)。

## 主要变化

- 采集原生设备帧位置、时钟和不连续标志。松开说话键后读取覆盖停止时间的尾包；检测到音频缺口或尾包不完整时保留文字、取消自动输入。
- 麦克风启动先于词库数据库刷新；启动缓存扩展到 15 秒，正常上传积压保持 5 秒限制。轻声讲话时持续更新的识别结果不再被固定音量阈值误判超时。
- 增加“仅听写，完成后手动复制”，主窗口和托盘均可切换。恢复起录时短暂焦点缺失；F8/F9 正确拦截右 Ctrl 组合键。
- UI Automation 查询使用唯一可终止的隐藏工作进程，挂起后可在下一轮恢复；长文输入预算包含逐批辅助功能查询时间，旧目标令牌不能恢复后继续输入。
- 浮窗显示最新文字、音量和计时，跟随目标显示器；暂停、就绪、收尾、整理与输入状态独立刷新，快捷键和版本文案动态读取。
- 专业词库保留 `mA/MA`、`Co/CO` 等大小写区别；同一标准词支持多个已确认别名，逐条启用、关闭或撤回，明确显示冲突和替换链原因。
- 确认纠错保护中文正负、指数和数量比较。扩展经规则校验的口吃删除与有限标点整理，继续保护数字、单位、引文、否定和语序。
- 数据库故障自动降级到无记忆听写，未来 schema 禁止继续读写；历史期限保存后立即执行并每分钟维护。真正保存失败持续提示，输入成功不会覆盖告警。
- final 到达后校准自动分段时间；高采样率降采样采用相应长度滤波器，降低混叠。
- 发布过程回读服务器最终状态、检查 tag 提交和附件哈希，处理客户端错误但服务器已完成的情况。

## 升级

从托盘退出旧版并备份用户数据目录后运行新版。数据库仍为版本 3，保留设置、手动权重、项目、历史和已确认纠错权限。旧版已经合并删除的大小写词条不能自动恢复，应重新导入需要并存的专业写法。

## 验证范围

发布门包含核心/存储回归、锁定依赖的 Windows x64 构建、发布恢复脚本测试，以及实际 EXE 的离线 WPF、DPAPI、SQLite、浮窗和 UIA 工作进程检查。具体通过数量与结果见本 Release 的 `build-output.log`。

这些检查不调用真实麦克风或付费云端接口。真实识别准确率、设备首尾音频、跨应用输入、IME 与混合 DPI 仍需 Windows 实机语料验收，本版未声明测得 CER/WER 或延迟指标。
