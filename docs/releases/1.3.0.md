Windows 语音输入法 1.3.0

新增纠错学习：从用户手工修正中生成待确认候选，确认后加入词库，并用于热词和全文润色保护。支持忽略、恢复和撤销学习，按项目隔离记录，学习记录加密保存。

本 Release 由 GitHub Actions 从标记提交运行项目回归测试并构建。提供 Windows x64 自包含单文件 EXE、源码 ZIP、构建日志和 SHA-256 校验文件。

下载 VoiceInput-Windows-x64-1.3.0.exe 即可运行，无需另装 .NET。程序未进行代码签名。自动测试不覆盖真实麦克风、目标窗口输入和付费云 API；焦点丢失问题仍需要 Windows 实机验证。

首次启动会将数据库升级至版本 2。回退到 1.2.1 需要恢复升级前备份。
