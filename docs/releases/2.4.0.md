# VoiceInput 2.4.0

## 默认开启高精度模式

- 实时显示识别文字，松开后使用百炼 Qwen-Audio-3.0-ASR-Flash 对完整录音再识别一次，再执行纠错、润色与智能标点。
- 复用现有百炼 Key、地域、业务空间与本轮热词；无需新增账号。设置中的“高精度模式”可随时关闭，旧配置升级默认开启。
- 每轮最多复核 3 分钟音频，等待上限 12 秒。超时、失败、空白或明显截断返回时采用实时识别结果；回车跳过等待，Esc 取消输入。
- 整段复核会增加一次 ASR 调用和相应费用，用量单独记录为 asr_review。音频只在内存中临时保存，处理后释放。
- 只在最终结果确定后复制和粘贴一次，迟到结果不会覆盖用户编辑、已输入文字或新会话。
- 被复核替代的流式原文不参与重复学习；复核结果作为 ASR 原文继续参与词库提取，不作为人工纠错证据。

## 验证范围

新增协议、默认设置迁移、完整音频缓存、超限回退、持久化、取消、超时及迟到结果等离线回归检查；发布流水线执行 Windows 构建、桌面启动和安装/更新交接/卸载检查。离线测试不代表真实语音准确率提升幅度，实际效果以使用场景为准。
