# VoiceInput 2.4.1

## 剪贴板短暂占用修复

- 修复剪贴板被其他软件短暂占用时过早放弃复制的问题：原先只等待约 100 毫秒，现在复制与回读共享约 1 秒的访问等待窗口。正常空闲时立即完成。
- 只有打开剪贴板失败才重试，已写入的正文和粘贴动作不会重复执行；等待期间检测到新的剪贴板内容仍停止覆盖。
- 复制失败时浮窗明确显示“复制失败”，主窗口提示剪贴板可能仍是旧内容，请从程序中复制本轮文字。
- 日志补充复制、粘贴阶段的固定诊断代码及耗时，便于区分剪贴板占用、内容变化、辅助进程不可用及输入目标变化；不记录识别正文和剪贴板正文。

## 验证范围

Windows 原生测试新增独立进程持有剪贴板 600 毫秒及 1800 毫秒的场景，检查短暂占用恢复、持续占用超时、旧内容保留、无误粘贴和后续复制恢复。保留已存在的无焦点复制、剪贴板被新内容替换时停止粘贴等检查。

这一修复针对可确认的短暂占用失败路径，不代表所有 Win10 输入失败均由此导致。具体应用的复现仍需结合版本、操作步骤和运行日志判断。
