Windows 语音输入法 1.3.1：输入焦点稳定性修复

修复内容：
- 在物理说话键按下时捕获目标窗口，避免信号排队后才读取输入目标。
- 区分明确切换窗口/控件和暂时读不到焦点；后者最多等待 500 毫秒恢复。明确切换后停止自动输入，切回也不会自动续发。
- 辅助功能查询使用有界等待与有限重试，避免原先 300 毫秒超时带来的误判；超时调用仍占用查询门锁，防止阻塞线程不断堆积。
- 通过辅助功能树中的原生窗口祖先确认输入框归属，兼容由独立进程提供辅助功能接口的控件。
- 键鼠操作立即使当前投递失效，避免事件队列处理延迟造成继续输入。
- 加强浮窗不激活处理；保留密码框、只读控件、输入法组合输入和选区变化检查。
- 将不可编辑、密码框、候选词未确认、接口暂时无响应等情况分别提示。

新增 9 项焦点与查询并发回归测试。此 Release 仅在完整测试与 Windows x64 构建成功后发布。自动测试不覆盖交互式桌面、真实麦克风和云 API；具体应用中的光标恢复效果仍需实机确认。

EXE 为 Windows x64 自包含单文件，无需另装 .NET，未进行代码签名。数据库格式沿用 1.3.0。
