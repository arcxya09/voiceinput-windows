# VoiceInput 2.1.8

- 无焦点也完整完成识别、尾句收齐、已启用的文字处理及自动复制。结果直接进入剪贴板，浮窗显示“已复制”；无需回到管理窗口点击复制。
- “仅听写”模式同样自动复制。识别结果留在程序和剪贴板中，不恢复旧剪贴板内容。
- 复制与自动粘贴分离：先确认完整正文已复制，再在原目标有效时发起一次 Ctrl+V。没有输入焦点、明确只读/禁用或持续失焦时，只复制，不强行切换窗口或粘贴。
- 兼容不提供完整辅助功能接口的编辑器：原窗口及非零原生焦点稳定时，未知 UIA 控件能力可使用整段粘贴；可见光标、光标坐标和 UIA 文本接口均不作为这条兼容路径的必要条件。已取得的目标及选区验证仍保留。
- 限制 UIA 捕获等待，避免辅助功能接口无响应导致识别长时间停在连接阶段。明确识别出的密码框仍拒绝启动。
- 保留剪贴板竞争检测、修饰键检查和一次粘贴原则。剪贴板写入失败时提示待复制；已发起的粘贴不会自动重试，也不会逐字模拟输入。
- 明确取消、短按、空结果及未完整结束的识别不会触发自动复制；完整流程使用相同的文字处理设置和快速交付等待预算。

提供 Windows x64 安装版和便携版。按住说话的 OS/音频边界使用生产服务及控制器回归；实际 Windows 冒烟验证无焦点复制、整段粘贴、剪贴板竞争及安装/卸载。尚未在用户的具体 Win10 软件中进行实机验证。
