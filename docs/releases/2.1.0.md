# VoiceInput 2.1.0

本版集中修正 WinUI 3 界面与窗口外框问题，提供安装版和整理目录后的便携版，并增加开机自启动。

## 界面修正

- 托盘右键菜单与识别浮窗统一处理原生窗口边框、客户区、圆角和 DPI，避免内部控件圆角与外层矩形窗口不一致。
- 识别浮窗继续保持小尺寸、目标屏幕底部居中、鼠标穿透和不抢焦点。
- 调整窄窗口中的工具栏与词条列表布局；修正列表空白双击误操作、刷新丢失多选等问题。
- 对话框随可用空间调整尺寸，保留滚动与键盘操作。

## 两种发行方式

- `VoiceInput-Setup-2.1.0.exe`：安装到当前用户目录，提供快捷方式和卸载入口，无需管理员权限。
- `VoiceInput-Portable-x64-2.1.0.zip`：完整解压后运行顶层 `VoiceInput.exe`。运行依赖集中放在 `app/`，许可证放在 `licenses/`。

两种版本均包含所需运行时，继续使用 `%LOCALAPPDATA%\RealtimeTranscription` 中的原有配置、API Key、词库和历史。升级前退出旧版；卸载保留用户数据。便携目录不包含个人数据，复制程序目录不会迁移 DPAPI 加密的数据。

## 开机自启动

设置中新增开机自启动开关，默认关闭。开启后于当前 Windows 用户登录时静默驻留托盘，按快捷键才开始录音。界面读取 Windows 启动注册状态，并尊重系统“启动应用”中的禁用设置。

移动便携目录后，手动启动新位置的 `VoiceInput.exe` 并检查自启动状态。卸载仅清理指向当前安装位置的启动项。

## 验证与附件

发布流程检查业务回归、发布恢复逻辑、最终便携包启动、原生窗口外框实际桌面截图、响应式布局和隔离的自启动注册；安装包执行静默安装、程序启动及卸载检查。结果见 `build-output.log` 和对应 GitHub Actions 记录。

真实麦克风、云端识别、外部应用输入与不同硬件的混合 DPI 多显示器仍需实机验证。
