# VoiceInput 2.1.5

自动上屏改为整段复制粘贴。针对部分软件仍出现“识别结果正确，输入后个别文字被标点替换”的反馈，完整正文先写入剪贴板，再通过一次 Ctrl+V 交给目标文本框处理，不再逐字模拟键入。

- 中文、标点、emoji 和段落换行随完整正文一起粘贴，不拆成字符或识别片段多次输入。
- 正文留在剪贴板，替换此前的剪贴板内容，可供再次粘贴。程序不定时恢复旧内容，避免目标应用延迟读取剪贴板时取得错误文字。
- 保留原输入目标、插入点或选区、密码框、只读区域、物理按键和输入法组合态检查。目标无法确认时保留识别结果供手动复制。
- 剪贴板被占用时有界等待；仍不可用则结束自动投递，不无限重试。粘贴快捷键可能已经发出后，不重试粘贴，也不回退到逐字键入，避免重复插入。
- 完成提示改为“已发起粘贴”，明确区分快捷键已提交与目标应用实际接收文字。用户仍自行确认和发送聊天、搜索或表单；程序不附加 Enter。
- 剪贴板准备与辅助功能检查在可终止的独立工作进程中执行，等待超时可退出，不占用界面线程。

回归检查覆盖整段只投递一次、取消与焦点变化、剪贴板不可用或被改写、部分快捷键事件及结果未知等路径。Windows 输入检查覆盖普通文本框、富文本框、选区替换、emoji、多行正文与延迟粘贴，并包含两条反馈原句：

> 感觉好像就不太准确。
>
> 测试一下这次的输入是否准确。看起来没有什么问题。

具体测试结果以对应 Actions 记录为准；受控文本框验证不能代替用户实际软件和输入法组合的复测。本次调整输入方式，不据此断言已确认原问题根因或所有编辑器均兼容。

继续提供 Windows x64 安装版和 Portable 版。升级前退出旧版；Portable 完整解压后运行顶层 `VoiceInput.exe`。配置、词库和历史继续沿用。自动上屏会使用剪贴板；如需完成后自行选择复制与粘贴位置，可开启“仅听写”。
