# VoiceInput 2.1.3

识别浮窗改为原生 WinUI 3 单行磨砂胶囊。

- 可见区域约 360 × 56 DIP，两端半圆，细描边、柔和阴影；在目标屏幕工作区底部居中，距离任务栏上沿约 24 DIP。
- 左侧音量指示、中间实时识别文字、右侧计时。长句显示最新文字，保持完整的 Unicode 字形；系统大字体会适当增大胶囊。
- 结束后保留最终文字，按真实投递结果显示“已输入”“待复制”“已取消”“部分输入”或“请核对”，避免把未知或部分输入误报为成功。
- 正常完成后停留 3 秒并淡出；新轮次和保存告警可取消淡出，保存失败持续提醒。尊重 Windows 的动画设置。
- 使用原生桌面 Acrylic 和透明窗口宿主，并为材质外沿启用抗锯齿。关闭透明效果、高对比度或运行时无法提供材质/平滑外沿时，回退为清晰的实色胶囊。
- 保留不抢焦点、鼠标穿透、旧轮次事件过滤及最终文字预览。托盘菜单沿用原有窗口实现。

验证包括业务回归、真实 Windows 可执行文件的单行布局/文字/状态/生命周期检查，以及受控桌面背景下的胶囊透明外沿和呈现检查。实际磨砂强度由 Windows、显卡和系统设置决定；虚拟机截图不作为实机磨砂或物理混合 DPI 的验收结果。

继续提供 Windows x64 安装版与 Portable 版。升级前从托盘退出旧版；Portable 完整解压后运行顶层 `VoiceInput.exe`，应用依赖集中在 `app` 目录中。
