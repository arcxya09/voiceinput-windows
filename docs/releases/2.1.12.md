# VoiceInput 2.1.12

本版针对智能标点、浮窗收起、音频环境自适应，以及 Win10 实测中的普通操作误取消、润色等待和采集诊断进行优化。

当前为未发布的源码候选版本。静态检查已完成；C# 回归测试、Windows 编译、桌面与安装程序验证尚未执行通过，下载文件尚未生成。

- 普通按键、鼠标按钮/滚轮操作立即关闭本轮自动粘贴资格，保留录音、识别、润色和自动复制。焦点恢复不会重新启用该轮粘贴。复制或粘贴准备期间的操作也遵循此规则。
- Esc、程序退出、录音时长限制和真实设备故障保留明确的终止流程；普通操作不再共用该取消条件。明确识别到的密码框仍拒绝上传。
- 默认快速模式最多等待润色 800 毫秒，超时采用完整识别正文及已确认纠错。等待有独立上限，迟到结果不覆盖会话、剪贴板或输入框。关闭“优先快速上屏”可等待完整润色，松键后的普通回车仍可加速。
- 主动取消、回车加速、润色等待超时和真实请求故障分别记录。普通输入只记录类别和阶段，不记录具体按键、鼠标位置或输入内容。
- 每轮新增 `TurnSummary`，记录音频时长、采样异常、字符数、投递结果和分阶段耗时。
- 采集循环新增取包间隔、包处理耗时、连续读取批次统计和异常阶段。日志在读完当前可用音频批次后写入；音频队列块改为值类型，减少逐包对象分配。保留现有共享事件采集模式与异常包收尾，不更改初始化时长参数。

## 验证与实测

已编写的回归用例覆盖启动、录音、润色、复制、粘贴准备中的普通输入，Esc、密码框、迟到润色和连续 20 轮录音。仓库的 Windows 桌面检查设计为使用生产采集循环配合模拟设备，覆盖异常包和长序列读取，并验证安装、启动与卸载。

CI 不能替代 Win10 17763 的具体驱动和负载实测。采集稳定性是否改善、真实上屏延迟的 P50/P95，需要本版日志进一步测量；本地音频收尾 P95 ≤100 毫秒是优化目标，尚不宣称实机达标。

### 智能标点与完成浮窗

- 语音识别设置新增默认开启的“智能标点”。单词、短语或简短单句省略冗余句末句号；问号、感叹号、省略号、多句、引文与专业符号保留。采用保守的 12 字中文 / 5 个英文单词且 48 字符阈值；关闭润色、超时或回车加速同样生效。保留原始识别内容，历史记录和剪贴板使用相同的最终正文，手动编辑优先。
- 默认润色提示词同步调整。旧默认提示词自动升级，用户自定义提示词保留。
- 已发起粘贴后的胶囊停留改为 450 毫秒，加 180 毫秒淡出；仅复制成功停留 1.2 秒，错误和需处理提示继续停留 3 秒，未保存警告保留。新一轮录音取消上一轮的隐藏动画。
- ASR 保留 VAD 低延迟断句，智能标点在完整结果生成后处理。[阿里云客户端事件文档](https://help.aliyun.com/zh/model-studio/fun-asr-client-events)说明语义断句参数切换的是断句方式，不是句末标点的样式。

### 音频环境与 ASR 参数

- 新增默认开启、可关闭的音频环境自适应。以 20 ms 窗口分析实际上传的 16 kHz 单声道 PCM，统计最近最多 8 秒的交流能量、低分位底噪、高分位活动电平、动态范围及削波比例。统计不保存音频。
- 至少观察 600 ms，且存在持续 120 ms 以上的活动及足够动态范围，才选择轻声、清晰或有噪声的语音候选环境。纯静音、平稳噪声、孤立点击、直流偏置、明显削波或样本不足均保留默认阈值。能量统计不能严格区分人声、音乐和其他动态噪声，仍以云端识别为准。
- 轻声候选使用 speech_noise_threshold=-0.1；底噪较高且语音与背景可分辨时使用 +0.1，并开启 multi_threshold_mode_enabled。保留 VAD 断句、用户设置的断句停顿和原始 PCM，不做本地降噪门限、增益或音频丢弃。
- 在 WebSocket 连接完成、发送 run-task 前读取统计，不额外等待校准。样本不足时可参考同一实际麦克风两分钟内成功完成的上一轮；当前已足量的统计优先。切换设备、过期、异常或不可判断的完整轮次不会复用旧档案。运行中不发送接口不支持的动态参数更新。
- 新增 AsrTuning、AudioEnvironment 日志：选参来源、环境类别、底噪／活动电平估计、动态范围、削波率及实际发送参数。dBFS 是数字音频电平，非实际声压级；分位数差值是动态范围估计，非已标定的真实信噪比。

参数依据：[阿里云客户端事件文档](https://help.aliyun.com/zh/model-studio/fun-asr-client-events)。自动选参阈值是保守启发式，合成音频测试只验证算法和请求链路，真实识别准确率还需麦克风与云服务实测。
