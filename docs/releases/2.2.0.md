# VoiceInput 2.2.0

本版新增 GitHub 软件更新。首次从 2.1.x 升级仍需下载安装包；安装 2.2.0 后可在软件内获取后续版本。

## 使用方式

设置页新增“软件更新”：显示当前版本，支持检查更新、下载或重新下载、取消下载、打开版本说明，以及“退出并安装”。

- 默认启动约 10 秒后检查 GitHub 正式版，之后每 6 小时检查一次；只接受高于当前版本的稳定版，不降级、不安装草稿或预览版。
- 默认发现新版后在后台下载安装包，期间可继续使用语音输入。可分别关闭自动检查、自动下载，点击页面底部“保存设置”生效。
- 下载完成且 SHA-256 校验通过后，点击“退出并安装”，软件先确认数据保存完成，再启动安装程序。安装程序等待当前进程退出后才开始安装；不会强制终止录音或覆盖运行中的程序。
- 安装版还可开启“托盘空闲 1 分钟后自动退出并打开安装程序”，默认关闭。管理窗口打开、正在输入、管理操作进行中、设置尚未保存或仍有未保存内容时不会自动退出。安装向导仍需用户完成。
- 便携版支持检查和下载安装包，点击安装时明确提示转为安装版。原便携目录保留，更新后请使用安装版快捷方式。配置、词库和历史仍使用同一 Windows 用户的数据目录。

## 下载与异常处理

只访问本仓库的 GitHub Releases。精确匹配安装包名称和版本，校验文件长度、发布清单中的 SHA-256，并在 GitHub 提供资源摘要时交叉校验。下载采用临时文件，校验后才生成安装包；启动安装前再次校验并持有只读句柄。

网络失败、限流、超时、取消、资源尚未上传完成或校验失败均保留当前版本，可在设置页重试。更新请求不携带 ASR/润色密钥、识别正文或录音。关闭软件会取消后台更新请求。

## 交付与验证

- `VoiceInput-Setup-2.2.0.exe`：安装版。
- `VoiceInput-Portable-x64-2.2.0.zip`：便携版。
- 离线回归覆盖数值版本比较、预览版排除、恶意地址、摘要和大小不匹配、取消、限流、更新设置持久化与保存失败阻断。
- Windows CI 覆盖原生桌面、安装卸载，以及安装程序等待指定父进程退出后再更新的实际交接。

GitHub 网络在不同地区的可用性、真实新版通知及完整的跨版本交互仍需实际网络环境验证。哈希用于确认下载完整性，不能替代代码签名或防范仓库本身被篡改。
