# VoiceInput 2.1.10

- 新增自动运行日志和设置页“导出运行日志”，汇总近期记录为一个 `.log` 文件，方便按故障时间定位。
- 细分麦克风枚举、选择、接口激活、格式读取、WASAPI 初始化、启动、首包及停止阶段，保留线程、HRESULT、耗时和设备哈希；记录禁用/拔出端点及三种默认角色的查询结果。
- 记录程序启动、识别连接、结果计数、文字处理、复制粘贴、取消、存储异常和退出过程，使用本轮标识关联。后续录音和测试不会覆盖原有故障记录。
- 日志后台写入，按约 2 MiB、UTC 日期、7 天和最多 10 个文件滚动清理；日志故障不影响录音。准备麦克风卡住时仍可导出，导出失败不会留下伪完整文件。
- 日志不含 API Key、音频、识别正文、提示词、词库、窗口标题或设备原始名称，不自动上传。
- 单个设备名称读取失败时，以临时名称保留其选择入口，并在日志中记录该属性故障。

提供 Windows x64 安装版和便携版。使用说明见[运行日志](../Runtime-logs.md)。

验证覆盖真实文件滚动、保留策略、并发写入、故障与取消导出、敏感内容排除、控制器故障历史，以及 Windows 设置页在麦克风构造被阻塞时导出日志。Windows 托管 CI 未连接真实麦克风，也不是 Win10 实机；本版提供定位依据，不宣称已经复现或消除用户的全部麦克风问题。
