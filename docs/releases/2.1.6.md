# VoiceInput 2.1.6

- 松手等待自动上屏时，普通 Enter 跳过剩余润色，不再取消本轮。该次 Enter（包括重复和松键）不会发送给目标软件；Esc 仍取消。录音期间、组合键、鼠标和焦点变更的保护保持有效。
- 新增默认开启的“优先快速上屏”：完整收齐 ASR 尾句后，最多等待全文润色 3 秒，超时采用完整识别正文和已确认的本地纠错。可关闭该选项等待完整润色；这不是整个松手到上屏过程的 3 秒保证。
- 自动上屏不再等待额外的词库重新加载；下次识别开始前仍通过数据库屏障刷新词库。正文保存和失败提示仍保留。
- 仍以一次 Ctrl+V 整段上屏，避免逐字输入导致的标点替字。粘贴前在同一剪贴板锁内冻结原来的格式；确认目标输入框出现预期完整文本后恢复原剪贴板。期间有新复制操作则保留新内容。
- 剪贴板确认在上屏之后进行，不以固定延时猜测目标已读取。辅助功能不支持确认、文档超过 64K 字符、原文与替换结果相同、或 1.5 秒内未确认时，保留识别正文，不冒险恢复。原剪贴板超过 32 MiB、格式超过 128 种，或包含不支持安全复制的私有句柄/调色板/图元文件时，停止自动粘贴，保留原剪贴板和程序内识别正文。

提供 Windows x64 安装包及 portable；portable 解压后运行根目录 VoiceInput.exe，依赖放在 app 子目录。

验证包括生产控制器的润色超时/回车取消、按键配对，以及 Windows 独立普通/富文本控件的实际粘贴和剪贴板恢复（含延迟读取、中文原句、选区替换、换行、emoji）。
