## 1.0.1 故障回归（保留）

完整收发回归运行正式程序的 `BailianClient`：录音前缓存 → `run-task` → `task-started` → 二进制音频 → 空用量中间结果与心跳 → `finish-task` → 最终句 → `task-finished`。检查了上传字节完整一致和没有错误事件。此测试使用进程内模拟 WebSocket，没有建立真实网络连接。

新增麦克风测试入口、格式快照、诊断 UI 和任务故障提示均已通过 Windows 目标编译；WASAPI 原生设备调用和新增按钮尚未进行 Windows 实机验证。

## 交付内容和实现说明

提供实际 EXE、源码、依赖锁文件、构建脚本、Markdown 设计与使用说明。单文件 EXE 可独立启动，不需要随附 PDB；内部原生组件首次启动时可能解压。未进行代码签名，未包含安装向导或自动更新服务。

本程序通过托盘工具、全局物理按键监听和 Unicode SendInput 提供语音输入，不是已注册的 TSF 语言栏服务。主流程使用一次长按对应一条记忆记录；界面将部分内部准备/收尾阶段合并显示。配置文件采用实际实现的 camelCase 属性，技术文档中的分组 JSON 表示逻辑配置组织。

词库导入提供整批校验、总量确认、重复跳过和事务写入；尚无逐条冲突采用界面。数据表将同一实体的部分设计字段保存在加密 JSON 负载内，并非设计逻辑实体各建一张表。当前没有通用转发地址、原生语言栏候选窗或向外部文档回写历史编辑。1.2.0 已实现本轮全文轻量润色。
