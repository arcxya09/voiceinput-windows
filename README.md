在其他应用的文本框中，按住右侧 Ctrl 说话，松开即停止录音。程序收齐尾句并完成最小幅度润色后，将结果写入原输入位置。快捷键支持 RightCtrl、F8、F9，可在设置中修改。

## 主要功能

- **Max 词库生成**：勾选“开启 Max 思考深度”，专业词库使用 DeepSeek Flash 的 Max 模式；保留普通模式选择。
- **全文统一润色**：一次长按只在松开并收齐尾句后发起一次全文润色，不按 ASR 片段调用 AI。正文、复制、导出、自动输入及历史查看使用同一份结果。
- **长语音输入**：默认可连续按住 10 分钟，最多可配置 30 分钟。静音断句默认 2.5 秒，关闭主动限制长句的多阈值模式；服务端结果在客户端合并。
- **全部历史提词**：在“历史记忆”或“设置”点击“提取全部历史词条”，扫描本软件全部项目的已保存记录，支持取消和续跑。候选保留原文证据，需确认后启用。

本版继续包含可编辑润色提示词、AI 领域词库生成、程序 Logo，以及百炼空值响应修复。技术细节见 [1.2.0 更新说明](docs/更新记录_1.2.0.md)，测试和实机验证范围见[验证记录](docs/验证记录.md)。

从托盘完全退出旧版，备份原数据目录后运行新版。现有 Key、历史记忆、词库和快捷键继续读取；数据库升级为版本 2。旧 EXE 不能直接读取升级后的数据库，回退需要恢复升级前的备份，详见[升级说明](docs/更新记录_1.3.0.md#升级与回退)。

## 快速使用

1. 双击 `VoiceInput-Windows-x64-1.3.0.exe`，在“设置”中填写阿里云百炼 API Key、地域、业务空间 ID，以及 DeepSeek API Key。不要把 Key 发送给他人。
2. 若使用官方兼容地址，可勾选“使用兼容地址”；否则业务空间、地域和 Key 必须对应。选择麦克风，点击保存。
3. 可分别点击连接测试。测试会实际发起少量 API 调用并可能计费；没有 Key 时不会发起测试。
4. 在记事本、文档或浏览器等应用的可编辑文本框中放好光标，按住右侧 Ctrl。悬浮提示显示麦克风就绪后讲话；默认长按确认时间为 150 ms。
5. 松开快捷键。麦克风停止采集，程序继续处理已采集音频与尾句，结果就绪后输入。不会额外按回车发送消息。
6. 若提示目标变化、无法识别编辑区域或输入受限，双击托盘图标，在“最近输入”复制结果，再自行粘贴。程序不会从头自动重发已部分输入的文字。

首次启动打开管理窗口；配置完成后，关闭窗口默认收至托盘。后续启动有 Key 时进入托盘。请使用托盘“退出”彻底关闭程序。

## 提示词和领域词库

在“设置 → 润色提示词（可编辑）”修改内容后点击“保存提示词”。“恢复默认”会填回默认内容，需要再次保存才生效。试用当前内容可直接显示采用结果，试用也会调用 DeepSeek。超出既有轻量整理规则的改动仍会保留原文。

在“设置 → AI 生成专业词库”填写领域要求，目标数量设为 100，再点击生成。每批最多 50 个；可取消，已完成结果留在预览中。检查和修改结果后点击“导入选中词条”，默认启用，下次录音生效。未导入的预览不会在退出后保留。生成和会话词条整理共用每日预算，余额不足或有效词条不够时会显示实际数量。

生成使用上方 DeepSeek Key，无需配置新接口。直接试用或生成时可以使用尚未保存的 Key；需要重启后沿用时请点击“保存设置”。生成要求、数量及 Max 开关也通过“保存设置”保存。Max 模式每批最多等待 3 分钟，输出上限 32,768 Token 包含思考；思考过程不会显示或存入词库。提高每日预算后须保存设置再生成。

## 麦克风测试与诊断

如果输入仍中断，打开“设置”，选择实际使用的麦克风，点击“本地麦克风测试（3 秒）”并讲话。测试使用同一套采集、声道合并、重采样和 PCM 分帧代码，但音频只在内存处理，不调用百炼或 DeepSeek，也不生成录音文件。

- 测试通过：显示采样格式、转换时长和低电平提示；之后可用“保存设置并测试百炼”检查云端连接，该测试可能产生少量费用。
- 没有音频：检查 Windows 麦克风权限、系统静音和选中的输入设备。
- 转换或连接失败：点击“查看录音诊断”，复制显示的版本、阶段、格式、异常类型或错误码。诊断只保留本进程最近一次，不写入日志文件；不包含 Key、录音或识别正文。

本地测试时按住说话暂时停用，测试结束恢复之前的启用状态。无需为了本地麦克风测试填写 API Key。

## 按住说话规则

- 左侧 Ctrl 不触发。长按产生的重复 key-down 不重复开录。
- 右 Ctrl 与 C、V、A 等键组成快捷键时，本轮语音取消，原按键继续传递。F8/F9 的物理事件也不被吞掉，请选择不会影响常用应用的键。
- Esc、其他键盘输入、鼠标点击或滚轮、输入焦点变化、设备变化、锁屏与睡眠会取消本轮自动输入，已确认结果仍可查看。
- 默认最长按住 600 秒（10 分钟），可调为 30—1800 秒（30 分钟）；到上限取消自动输入并保留确认文字供复制。未按住时不持续采集麦克风。
- 连接期间本地缓存最多 5 秒 PCM；任务就绪后才上传。缓冲满时终止，不悄悄丢掉开头继续。
- 上一轮收尾尚未完成时，再次长按会提示忙碌，不排队录下一段。请等结果提示后重新按住。
- 目标验证依赖 Win32 和 UI Automation。密码、只读、无法确认的控件及权限受限目标转为手动复制，不提权、不强制抢回焦点。
- Windows 接受输入事件不等于目标应用已保存文档或已发送消息。

首版作为托盘语音输入工具运行，不注册到 Windows 的 Win+Space 语言列表，也不替换现有拼音输入法。

## 识别和润色

百炼模型固定为 `qwen-audio-3.0-asr-flash-streaming`，采用任务式 WebSocket、16 kHz 单声道 PCM；DeepSeek 固定为 `deepseek-flash`，润色关闭思考，以非流式文本响应处理本轮全部已确认原文。录音期间只接收 ASR 结果，松开后收齐尾句再统一润色。

全文最多自动处理 30,000 个 Unicode 字符，等待时间按长度在 20—120 秒内调整。超过上限、取消或失败时保留完整确认原文，不截断后再润色，不把部分模型结果写入正文。

润色只允许已登记的局部语气词、口吃或冗余微调，保护数值、单位、方向、否定、引用和命中词条。模型越界、超时、认证失败或响应不完整时保留 ASR 原文。校验偏保守，部分合理润色可能回退；人工质量指标尚未实测。只有 ASR 完整、目标有效且该轮未取消时才自动输入。

API 地址固定为官方域名；配置自定义 Key 不意味着支持任意第三方代理地址。服务可用性和费用以用户账户及服务商实际响应为准。

- [百炼实时 ASR WebSocket](https://help.aliyun.com/zh/model-studio/fun-asr-realtime-websocket-api)
- [百炼客户端事件](https://help.aliyun.com/zh/model-studio/fun-asr-client-events)
- [DeepSeek API](https://api-docs.deepseek.com/)

## 记忆与词库

“最近输入”的“允许当前会话用于词条整理”独立保存该条历史的许可；设置中的“允许词条整理（新会话默认）”控制总开关及新会话初始许可。关闭某条历史的许可后，重新打开总开关不会将它纳入提取。旧版未保存的禁用许可无法自动恢复，升级后请检查需要排除的历史。

默认保存本地文本记忆，长期保留；不保存录音文件。每轮保留确认原文、最终文字、投递状态及编辑历史。可以在“历史记忆”按项目、时间、关键词检索，或清除记录。关闭保存后，新结果仍可输入、复制和导出。保留天数策略在程序启动时清理过期记录。

未保存计数包含片段、全文结果和会话状态。可在设置中点击“重试保存未保存内容”；切换会话后仍能重试之前失败的写入。重新载入失败保存的会话时，程序先重试，持续失败则保留当前文字。持续无法保存时，请在退出前复制或导出；未能写入磁盘的内容不能保证重启后恢复。

“对照与编辑”默认显示本轮全文原文与最终结果；“原始片段修订”只改本地记录，不自动改写已经输入的外部文档。修改来源片段后，旧全文润色结果失效，本地正文按修订后的各片段重新拼接。可以恢复原文、删除片段、撤销编辑，并通过“记住此写法”保存明确的标准词条。词库不执行无条件别名替换。

### 纠错学习

在“对照与编辑 → 原始片段修订”改正错词并点击“保存编辑”，然后打开“词库 → 纠错学习”，选中候选并“确认学习…”。确认窗口可修改标准写法、分类、权重和项目或全局范围。候选生成要求文本记忆、词条整理、纠错学习及会话学习许可同时开启，且正文成功保存。模型自动润色不会触发学习。

同一片段重复保存不增加次数；在不同片段反复纠正同一组写法才累计。可以查看来源、忽略误判、恢复候选或撤销学习。中文自动词条边界可能不准确，确认前请检查。关闭纠错开关暂停后续发现；已确认词条仍可在词条管理中调整或删除。候选生成在本地完成，确认词条的云端使用沿用普通词库规则。详见[1.3.0 说明](docs/更新记录_1.3.0.md)。

### 词条管理与整理

词库支持当前项目和全局范围，添加、编辑、禁用、删除、权重、保护写法、来源与导入导出。相同范围重名导入项按 NFC 规范化、去除首尾空白和不区分大小写的规则跳过，不覆盖现值；导入先校验再确认，以单一事务写入。每个范围最多 5,000 条，每轮最多选择 200 个热词。

“整理当前会话词条”会把符合保存与学习条件的文本发送到 DeepSeek，生成待确认候选。候选确认后才参与识别。自动整理默认关闭，每次最多处理 5 批，长片段按 Unicode 边界切片，完成游标可继续处理后续内容。每日预算包含已知实际用量和未知请求保留的预留额。

### 从全部历史提取

在“设置 → 从全部历史提取词条”或“历史记忆”点击“提取全部历史词条”。该操作会保存当前设置，再遍历本软件所有项目的历史输入。它不读取其他聊天软件或 ChatGPT 的聊天记录。

每页读取 100 条会话，每次请求最多 2,000 字、20 个来源片段；处理范围没有 500 条历史列表限制，也没有当前会话整理的 5 批上限。没有保存、已经删除、未确认或未允许整理的内容不会上传。AI 润色不作为学习原文，避免把模型自行改动的词再次学回去；用户手动修订过的片段使用修订文本。

新增候选进入来源项目词库；重复项合并来源，保留原有启用状态、分类和权重，不复活删除项或重新启用禁用项。取消、网络中断或预算不足时，已完成批次和来源版本游标一起保存，再点按钮即可继续。新录音会取消正在进行的历史提取。所有词库 AI 功能共用每日预算，按 UTC 00:00 重置（中国标准时间 08:00）；ASR 和普通全文润色不包含在此预算内。

### 导入格式

TXT：每行一个词条，默认在当前项目启用。CSV：UTF-8，包含 `text` 或 `词条` 表头，可加 `category`、`weight`、`scope`、`state`。例如：

```csv
text,category,weight,scope,state
JUNA,专业术语,4,*,Enabled
R-matrix,专业术语,4,current_project,Enabled
```

JSON 可直接使用软件导出的词库文件，也接受设计文档中的 `terms`、`enabled` 与 `protect_in_polish` 结构。导出不包含 API Key、音频或完整来源历史。需要追溯会话时使用独立的“导出记忆记录 JSON”。

## 文件和凭据

用户数据目录：`%LOCALAPPDATA%\RealtimeTranscription\`。

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 非秘密设置，实际文件使用 camelCase 属性 |
| `credentials.dat` | 当前 Windows 用户 DPAPI 加密的两套 Key |
| `sessions.db` | SQLite；文本、词条、项目名称及纠错候选上下文为 DPAPI 加密负载；查询索引并非全文加密 |
| `sessions.db-wal` / `sessions.db-shm` | SQLite 运行期文件；关闭程序后再备份 |

DPAPI 绑定 Windows 用户，复制数据库到另一用户或另一台电脑不保证可解密。TXT、Markdown 和 JSON 导出是明文，请自行选择保存位置。升级先退出旧进程并备份完整用户数据目录，再替换 EXE。1.3.0 会升级数据库；回退旧 EXE 时须恢复旧备份。单文件运行时会解压必要原生组件，EXE 不依赖旁边的 PDB 文件。

此构建未进行代码签名。没有安装向导、开机自启或自动更新器。

## 从源码构建

安装 .NET SDK **10.0.401**；版本由 `global.json` 锁定。运行：

```powershell
.\build.ps1
```

脚本使用锁定还原、执行核心、协议、存储和协调器回归测试，再发布 Windows x64 单文件 EXE。依赖按运行标识分别保存锁文件，避免测试还原和 Windows 发布互相改写同一个锁文件。也可在 Linux 上交叉编译 WPF Windows 目标，产物仍需在真实 Windows 验证。

代码组织：

| 目录 | 内容 |
| --- | --- |
| `src/Core` | 片段状态机、最小改动校验、纠错差异规则、词库、提取切片及连续重采样 |
| `src/Infrastructure` | 百炼、DeepSeek、DPAPI、纠错学习事务和 SQLite 串行存储 |
| `src/Desktop` | WPF 管理页、WASAPI、托盘、设备通知及协调器 |
| `src/Desktop/Input` | 物理按键钩子、输入目标校验和 Unicode 投递 |
| `tests` | 可独立执行的核心、协议、存储和协调器回归测试 |
| `docs` | Markdown 设计与验证说明 |
| `licenses` | 随附第三方许可证及 .NET 第三方声明 |

重新发布自包含程序时应同时更新运行时安全补丁和依赖锁文件；本项目未内置 API Key 或远程业务服务器。
